# ROPO Fleet · 车队运营交互原型

基于提供的 7 张 Figma SVG 及补充地图图片制作的桌面网页原型。保留深色界面风格及原稿图片素材，使用原生业务代码与 React / Ant Design 组件，实现导航、表单、筛选、弹窗和状态变化。

## 在线访问

- 网页：[ROPO Fleet 在线原型](https://abdd33.github.io/ropo-fleet-prototype/)
- 仓库：[Abdd33/ropo-fleet-prototype](https://github.com/Abdd33/ropo-fleet-prototype)
- 直接打开[任务与调度](https://abdd33.github.io/ropo-fleet-prototype/#plans)。

仓库和网页均为公开。线上访问者的数据仍只保存在各自浏览器；本地文件和线上网址的浏览器保存状态不会自动同步。更新方式见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 打开方式

1. 完整解压项目文件夹，保留目录结构。
2. 双击 `dist/index.html`，在桌面浏览器中打开，无需安装依赖或构建。
3. 推荐浏览器内容区宽度 **1280 px 以上**；设计基准为 **1440 px**。复杂工作台在窄窗口中可横向浏览。

如果希望通过本地网址访问，且电脑已安装 Node.js，可在本文件所在目录运行：

```sh
node server.cjs
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。在终端按 `Ctrl+C` 停止服务。此服务只监听本机地址。

## 建议体验路线

1. 在 **运营总览** 点击车辆统计卡，进入对应筛选的车辆列表。
2. 在 **车辆管理** 搜索 `RT-021`，打开车辆详情，查看路线、诊断和操作记录。
3. 进入 **任务与调度 → 创建运行计划**，依次选择任务、路线与时间、车辆，检查后下发。默认场景日期为 **2026-10-23**，新计划默认 **11:10** 出发。
4. 在调度页选中计划，进入 **远程运营工作台**，检查条件并确认模拟发车。车辆和计划状态会同步更新；也可体验模拟停车、广播与自检。
5. 在 **任务与调度 → 自动化流程** 设置绑定车组与班次，查看运营准备、接单运营、回场补能和收班归巢四个阶段；进入主卡片编辑子步骤，检查流程后执行车组模拟，最后保存草稿或演示版本。

## 车组与分层流程

点击顶部“车组设置”，可选择已有车组或新建车组，编辑车组名称、成员车辆和当日班次时段，再“保存并绑定车组”。每个流程绑定一个车组，各成员车辆按自身状态独立模拟。离线、维修或已有补能任务的车辆保留在成员列表中，并在模拟结果中说明为何进入人工处理或等待。

主画布通过四张业务主卡片表达运营阶段；班次启动、下一步判定、异常处置和流程结束分别表达入口、分支、人工处理与出口。点击主卡片的“查看子步骤”，进入该阶段的独立画布；左侧组件库切换为当前阶段允许使用的子步骤。点击“返回主流程”退出。第一版只提供主流程与子步骤两层。

将左侧组件拖到画布，拖动时显示预览并高亮可放置区域。松手后按当前缩放与平移创建卡片，**只放置，不自动连接此前选中的卡片**。也可直接点击组件或聚焦后按 `Enter` / 空格添加；按 `Esc` 或在画布外松手取消拖入。补能触发 SOC、充电目标 SOC、等待时限等提供适当的快捷控件，各节点参数独立保存。

## 连接、断开与删除节点

- **手动连线**：从“准备完成”“需要补能”“检查异常”等命名结果出口拖至下一张卡片的输入端口；也可依次点击端口，或在右侧“结果与下一步”中选择目标。一个结果出口只能连接一个下一步，重新连接会替换原目标；不能直接连回自己或连接入口，按 `Esc` 取消尚未完成的连接。
- **断开连线**：点击画布上的连线，再点击“断开连线”；也可在右侧对应结果的下拉框中选择“未连接”。选中画布连线后按 `Delete` / `Backspace` 同样可断开。
- **快速删除**：把节点卡片拖入画布右下角垃圾桶，看到“松手删除节点”后松手。节点及关联连线会一起移除。也可使用右侧“删除节点”。
- **撤销删除**：点击垃圾桶下方“撤销删除”，恢复最近一次删除的节点、原位置及仍可恢复的关联连线。撤销记录保留在当前页面会话中，刷新后不保留。
- 修改后点击“保存草稿”。节点、子步骤、连线、车组绑定及删除结果保存在当前浏览器中。有待修复项的草稿仍可保存，但须通过检查后才能模拟或发布。

## 车组模拟与保存

可选择“按车辆当前状态”“低电量回场”“到达收班时间”“补能资源不足”“车辆数据缺失”场景。模拟分别沿每辆车的主流程连线、命名结果和子步骤连线执行，显示逐车结果、判断原因与步骤轨迹。点击轨迹可定位卡片，也可回放当前画布。普通运营场景观察一次任务及等待循环，并不假装完成整天运营。

人工处理或人工执行模式会暂停相应车辆的模拟；可继续“模拟处理后复检”或“终止本车模拟”。无资源场景按照设置进行有限等待和重试。修改流程会清除之前的模拟结果，避免将旧结果当作新配置的验证结论。模拟不修改真实车辆、运行计划或外部服务。

新版配置保存在演示状态的 `flowV2` 中，旧版 `flow` 草稿保留；首次创建新版流程时沿用有效的旧补能阈值，其余结构采用新的分层模板。车组库保存在 `automationGroups`。“发布演示版本”保存本地车组及流程快照，不会部署调度任务。所有资源均为本地静态文件，`dist/index.html` 仍可离线打开。

## 调度时间轴

时间轴按车辆分行，同车的历史、当前和后续任务放在同一行；初始场景包含 16 条排班，其中 10 条为灰色未触发任务。点击左侧车辆信息区可选中整行并联动右侧详情，优先显示红线所在时段的任务，否则显示下一条排班（当天任务都已结束时显示最近一条）；也可直接点击任务卡片查看。支持按日期、类型、状态和车辆搜索筛选。

拖动红色时间标签或竖线，可按 5 分钟步长预览排班状态和计划进度；选中游标后，方向键每次调整 5 分钟，Shift + 方向键调整 15 分钟，Home / End 跳到时间轴两端。点击“回到当前”恢复场景时间 10:20。游标位置随浏览器保存，预览不会下发任务或修改实际计划状态。未触发任务不能直接进入远程执行，仍可调整时段、换车或取消。

## 数据与保存

- 数据保存在当前浏览器的 `localStorage` 中；刷新页面后可继续查看已保存的计划、车辆状态、流程配置与操作记录。
- 直接打开文件与通过本地网址访问属于不同浏览器存储环境，演示状态不会自动互通。浏览器限制本地存储时，页面会提示当前操作仅在窗口内保留。
- **系统设置** 可导出演示状态 JSON、恢复初始数据；**记录与交班** 可填写交班记录并导出 CSV。
- 原稿存在重复车辆编号。原型使用 **50 个唯一车辆编号**，车辆统计按当前演示状态计算，因此部分数字会与静态原稿不同。

## 原型范围

地图、路线底图和摄像头画面来自原稿，均为静态素材；电量、时延、传感器、行程耗时和执行结果为演示数据。项目未连接真实车辆、实时地图、摄像头、调度平台或其他外部业务 API。发车、急停、派工、广播及“发布演示版本”只改变本浏览器中的演示状态。

SVG 中的文字已经转为矢量路径，无法直接恢复原始文本或 Figma 交互配置。本原型根据画面重建文字与组件，并补充推断的交互。逐页说明见 [INTERACTIONS.md](INTERACTIONS.md)。

## Ant Design 组件接入

已接入 Ant Design 6.6.8、React 19.3.1 和中文语言包，使用与原型配色一致的深色主题。任务与调度页使用 Button、DatePicker、Select、Input、Segmented 和 Tooltip；全局消息提示及确认弹窗通过 App 上下文消费主题。自定义时间轴、车辆选择与流程画布继续使用原有业务逻辑。

`dist/` 已包含预编译组件和版权声明，打开网页无需额外下载 React 或 Ant Design，也不依赖 CDN。修改组件源码 `src/antd-ui.jsx` 或其样式后，需要重新构建（Node.js 与 pnpm 11）：

```sh
pnpm install --frozen-lockfile
pnpm run build
node server.cjs
```

构建只更新 `dist/antd-ui.js`、组件样式及第三方声明，不清空原有静态资源。主题配置集中在 `src/antd-ui.jsx` 的 `fleetTheme` 中。

## 地图交互更新

车辆详情页的“全局路径”使用提供的 Map Component.png（2824 × 2028），默认按视口宽度铺满并保持原图比例，超出视口的上下区域可拖拽查看。支持拖拽平移、滚轮缩放、双击放大、＋／−按钮和“适应宽度”复位；以适应宽度为 100% 缩放基准，最高可放大至 600%。聚焦地图后也可用方向键平移、＋／−缩放、0 或 Home 复位。地图仍为本地图片，不请求地图服务。
